# Integration Testing

yamlfmt has integration testing that tests invocations end-to-end.

## Run

Integration tests are excluded from `go test` by default using build tags. To build the binary and execute the integration tests against it, use:

```shell
just test-integration
```

`just test` runs them too, after the unit and race lanes.

## Update

The "golden" / expected output files can be (re-)generated by the test framework. To do so, run:

```shell
just test-integration -update
```

## Add new test case

* Run the following command from the repository root to create the directory structure for the new test:

  ```shell
  integrationtest/command/new_test_case.sh my_new_test
  ```
* Add example input files to `integrationtest/command/testdata/my_new_test/before`.
* Add the expected output to `integrationtest/command/testdata/my_new_test/stdout/stdout.txt` if applicable.
* The script added a new Go test to `integrationtest/command/command_test.go`. Update the `yamlfmt` flags so the invocation uses the feature the test should cover.
* Run the following command to generate the expected "golden" output of the test:

  ```shell
  just test-integration -update
  ```
* Review the generated output to ensure it is expected.
